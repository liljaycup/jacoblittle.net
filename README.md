# jacoblittle.net

The personal website of Jacob Little, writer of poetry and creative nonfiction.

Plain HTML and CSS, hosted on GitHub Pages at https://jacoblittle.net.

- `index.html`, `bio.html`, `publications.html`, `contact.html`: main pages
- One page per self-hosted piece, at the same addresses the old site used
- `assets/`: stylesheet, a small script, and images
- `CNAME`: tells GitHub Pages to serve the site at jacoblittle.net

The contact form sends through Formspree. Its form ID is in `contact.html`.
